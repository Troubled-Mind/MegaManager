Cloud Verification

Audit the MEGA cloud against your local database to ensure structure and file sizes match perfectly.

Any folders found to be missing, corrupted, or mismatched in size will be automatically deleted from the cloud and re-queued for upload.

This process scans every completed file across all active accounts using `rclone size`. It checks that the exact byte-size matches the original local footprint. If you have many large accounts, this may take several minutes.
